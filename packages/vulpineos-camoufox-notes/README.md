# VulpineOS Camoufox Notes

`vulpineos` packages the VulpineOS agent runtime. `camoufox-vulpineos` builds its
Camoufox fork from VulpineOS/VulpineOS source. Both pins track the latest checked
upstream snapshot, `f8579728616e892c364aa4c571f05db5869bc59f`.

The default `camoufox` browser instead builds daijro/camoufox source.
`cloverlabs-camoufox` is a separate Python interface, not the browser source.
