# Browser Packages

Vocabulary for browser products packaged by this repository. Related upstream products can share a source tree without sharing features or runtime components.

## Language

**BrowserOS neo**:
An agent-operated secondary browser with persistent user sessions. Distinct from BrowserOS, despite sharing an upstream source repository.
_Avoid_: BrowserOS, BrowserClaw (public product name)

**BrowserOS**:
A separate user-operated browser product with integrated AI capabilities. Not interchangeable with BrowserOS neo.
_Avoid_: BrowserOS neo

**BrowserClaw**:
Upstream internal product identifier for BrowserOS neo, used in source and release naming.
_Avoid_: BrowserOS (as an alias)
